#### 履歴の作り直し

リポジトリを一度作り直す作業である。間違えても戻せるように、最初にバックアップを取る。

1. **ほかの端末の作業を push しておく**。作り直したあとは、ほかの端末では clone し直すので、push していない変更は失われる。
2. **バックアップを取る**。リポジトリの外に、いまの履歴を丸ごと 1 ファイルに保存する。

   ```
   git bundle create ..\pikulix-old.bundle --all
   ```

3. **GitHub の noreply アドレスを調べる**。GitHub の Settings → Emails で「Keep my email addresses private」をオンにすると、`数字+kaiwaredaikon009@users.noreply.github.com` という形のアドレスが表示される。同じ画面の「Block command line pushes that expose my email」もオンにしておくと、Gmail のアドレスのままのコミットは push できなくなり、再発を防げる。
4. **作者の名前とアドレスを設定する**。使っているすべての端末で行う。名前は、LICENSE の著作権者（ぽよぽよ）に揃えるか、いまの名前（ぽよぴく）のままにするかを決める。

   ```
   git config --global user.name "名前"
   git config --global user.email "数字+kaiwaredaikon009@users.noreply.github.com"
   ```

5. **いまのファイルの状態だけを持つ、新しい main を作る**。

   ```
   git checkout --orphan new-main
   git add -A
   git status
   ```

   `git status` の一覧に、`samples/target.png`、`build/`、`vendor/` が無いことを確かめる（どれも `.gitignore` で除いている）。よければ、コミットして名前を付け替える。

   ```
   git commit -m "Pikulix を公開する"
   git branch -D main
   git branch -m main
   git log --format="%an <%ae>"
   ```

   最後の行の出力が 1 行だけで、手順 4 の名前とアドレスになっていればよい。
6. **GitHub のリポジトリを作り直す**。Settings → General のいちばん下（Danger Zone）の「Delete this repository」で消し、同じ名前（`pikulix`）で、Private のまま、README などを作らずに新しく作る。そこへ push する。

   ```
   git push -u origin main
   ```

   強制 push（`git push --force`）で済ませることもできるが、古いコミットが GitHub 上にしばらく残り、コミットの ID を知っていれば見られてしまう。リポジトリには Issues や設定がまだ無いので、作り直しても失うものは無い。
7. **ほかの端末では、古いフォルダを消して clone し直す**。古いフォルダで `git pull` すると、古い履歴とつながってしまう。
8. GitHub 上で、コミットが 1 つだけであること、作者のアドレスが noreply であることを確かめる。`..\pikulix-old.bundle` は、しばらく残しておいてから消す。
