# my-scripts

このディレクトリは、Pikulix で動かす RPA スクリプトを書くための場所である。Pikulix 本体を開発する場所ではない。リポジトリの直下にある `AGENTS.md` と `CLAUDE.md` は本体の開発のためのもので、そこにある作業ルール（`CLAUDE.md` や `docs/dev/` のノートを更新する、など）は、ここでは使わない。

本体のファイル（`../src/`、`../docs/`、`../samples/` など）は、読むだけにする。作ったファイルは、このディレクトリに置く。

## スクリプトの書き方

- スクリプトは mruby で動く。使えるのは、mruby（Ruby の文法と組み込みのクラス）と、`../docs/api.md` にあるメソッドである。
- 書く前に `../docs/api.md` を読む。「使えないもの」の節にあるものは使わない。
- 書き方の例は `../samples/` にある。
- Pikulix は SikuliX を参考にしているが、互換性は無い。SikuliX（Python）の書き方はしない。
- スクリプトは UTF-8 で書き、拡張子は `.rb` とする。
- 画像のパスは、スクリプトのあるディレクトリからの相対で書く。

## 画像

- 探す画像（PNG）は、利用者が画面から切り取って用意する。画像を作ったり、別の画像で代わりにしたりしない。
- 必要な画像がまだ無いときは、ファイル名と、画面のどこを切り取るかを一覧にして、利用者に頼む。

## 試しかた

- exe は `../build/pikulix.exe` にある。リポジトリの直下で `rake` を実行すると作られる。無いときは、利用者に伝える。
- 自分で実行してよいのは、テストモードだけである。テストモードでは、画面の代わりに画像ファイルの中から探し、マウスやキーボードは動かさない。画面の画像は、利用者に用意してもらう。

  ```
  ..\build\pikulix.exe --screen-image 画面.png スクリプト.rb
  ```

- テストモードでも、`message_box` は表示されて、閉じるまで止まる。`sleep` は実際に待ち、`write_text` などはファイルを実際に書く。
- テストモードを付けずに実行すると、実際のマウスとキーボードが動き、利用者のデスクトップを奪う。本番の実行は、利用者が自分で行う。了承を得たときだけ、代わりに実行してよい。
- 本番の実行を利用者に頼むときは、Alt+Shift+C を押せば止まることを添える。
- 画像が見つからなかったときの画面は、`../build/logs` に保存される。見つからない理由を調べるときに使う。
