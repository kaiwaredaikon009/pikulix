# 開発用の作業ノート

このディレクトリには、Pikulix を開発するための作業ノートを置いている。作成者と、開発を手伝う AI のコーディング支援ツール（Claude Code、Codex）が読み書きするもので、利用者向けの文書ではない。進み具合や、試して分かったこと、作成者への確認の依頼などを、作業しながら書き足している。

Pikulix を使うだけなら、ここを読む必要はない。利用者向けの文書は次のとおりである。

- [README](../../README.md): Pikulix の紹介と、はじめかた。
- [スクリプトの書き方](../api.md): API の一覧。
- [ビルド手順](../ビルド手順.md): 自分でビルドするときの手順。

## ノートの一覧

| ファイル | 内容 |
| --- | --- |
| [ロードマップ.md](ロードマップ.md) | 開発工程、現在の状態、作成者が行う確認、作成者の判断を待っていること。 |
| [設計と調査の記録.md](設計と調査の記録.md) | 仕様、技術方針、設計上の検討事項、調査や確認で分かったこと、実装しながら決めたこと。なぜいまの作りになっているかを知りたいときは、ここを読む。 |
| [人が行うテスト手順書.md](人が行うテスト手順書.md) | 実際の画面とマウス・キーボードを使うテストの手順。自動テストでは確かめられない部分を、作成者が実機で確かめる。 |
| [開発環境.md](開発環境.md) | 開発機の状況と、Windows 向けの開発についての予備知識。 |

プロジェクト全体の概要と作業上のルールは、リポジトリの直下の `CLAUDE.md` にある（`AGENTS.md` からも参照している）。
