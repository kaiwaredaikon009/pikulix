> 開発用の作業ノートである（[docs/dev/README.md](README.md)）。Pikulix を使うだけなら、読む必要はない。使い方は [README](../../README.md) と [スクリプトの書き方](../api.md) にある。

開発機の状況と、Windows 向けの開発についての予備知識をまとめる。ビルドの手順そのものは `docs/ビルド手順.md` にある。

作成者は Windows アプリの開発が初めてである。環境の準備も作業の一部として扱う。

## Windows 向けのコンパイラについて

exe を作るには、C や C++ のコンパイラが要る。Windows には主に 2 系統がある。

- **MSVC**: Microsoft 純正のコンパイラ。Visual Studio（または Build Tools for Visual Studio）に含まれる。インストールは数 GB になる。
- **MinGW-w64 の gcc**: Linux でおなじみの gcc の Windows 版。MSYS2 という配布物から入手できる。RubyInstaller に付属する「devkit」の正体がこれである。

このプロジェクトでは後者を使う。作成者の開発機にすでに入っているので、新たに入れるものが少ない。

## 開発機の状況（2026-11-15 時点）

- 作成者は複数の端末で開発しており、Windows 11 の Home と Pro が混在している。Home では Windows サンドボックスを使えない。以下は、最初に調べた端末の状況である。
- Ruby 4.0.5（RubyInstaller、`x64-mingw-ucrt`）があり、`rake` が使える。Home の端末（Ruby 4.0.6）でも、追加の準備なしで `rake test` が通った（2026-11-16）。
- RubyInstaller 付属の MSYS2 に、UCRT64 の gcc 16.1.0 がある。PATH には通っていないので、`ridk enable ucrt64` で有効にする。
- .NET は実行用のランタイム（8.0）だけがあり、開発用の SDK は入っていない。
- Visual Studio（MSVC）、CMake、`gh` コマンドは入っていない。

## 必要な準備

- コンパイラと Ruby は、追加のインストールなしで足りた（Phase 0 で確認）。`ridk enable` も要らない。PATH に gcc が無ければ、`Rakefile` が RubyInstaller 付属の MSYS2 を自動で使う。
- **.NET SDK と MSVC は要らない**。
- Windows サンドボックスは必須ではない。Pro の端末では、「Windows の機能」で有効にすれば `rake sandbox` で確かめられる（`docs/ビルド手順.md`）。
- 準備とビルドの手順は `docs/ビルド手順.md` にある。公開リポジトリなので、他の人がビルドするときにも要る。
