# スクリプトの書き方

Pikulix のスクリプトは Ruby（mruby）で書く。画面の中から画像を探し、マウスやキーボードを操作する。

```ruby
click "start_button.png"
wait "dialog.png", timeout: 10
type "こんにちは"
key "ctrl+s"

if exists("error.png")
  click "ok.png"
end
```

## 実行

```
pikulix.exe script.rb
```

スクリプトのファイルを `pikulix.exe` にドラッグ＆ドロップしても同じである。ただし、そのときは終わるとすぐにコンソールのウィンドウが閉じるので、エラーで終わってもメッセージを読む間が無い。エラーを読みたいときは、コマンドプロンプトから実行する。

- スクリプトは UTF-8 で保存する。
- **途中で止めたいときは、Alt+Shift+C を押す**。どのウィンドウが前面にあっても効く。押したままになっているキーやマウスボタンは離される。
- Alt+Shift+C をほかのプログラム（別の Pikulix など）が使っていると、Pikulix はこのキーを使えない。そのときは、止める手段が無いまま操作するのは危ないので、マウスやキーボードの操作をせずにエラーで終わる（`緊急停止のホットキー（Alt+Shift+C）を登録できなかったので、操作を中止しました。…`）。画像を探すだけ、出力するだけのスクリプトは、そのまま動く。Pikulix を 2 つ同時に動かさないようにする。
- 実行中、コンソール（黒い画面）のウィンドウは最小化される。操作する相手を隠したり、探す画像に写り込んだりしないようにするためである。Windows Terminal で実行したときは、ほかのタブも含めて、ウィンドウごと最小化される。
- 終了コードは、成功が 0、スクリプトのエラーが 1、起動できなかったときが 2、Alt+Shift+C で止めたときが 3 である。
- `pikulix.exe --version` で、バージョンを表示する（`pikulix 0.1.0` など）。

## 画像の用意

探したいもの（ボタンやアイコンなど）を、画面から切り取って PNG で保存する。Windows 標準の Snipping Tool（Win+Shift+S）が使える。

- 画像のパスは、スクリプトのあるフォルダからの相対で書く。日本語のファイル名も使える。
- 探すのは、プライマリモニタ（主となる画面）だけである。
- 画像を切り取ったときと、実行するときとで、表示倍率（拡大率）・テーマ・フォントが違うと見つからない。
- 背景が透けているもの、マウスを乗せると色が変わるものは、変わらない部分だけを切り取るとよい。

## 探す

| 書式 | すること |
| --- | --- |
| `find(画像)` | 画像を探し、見つけた場所（`Match`）を返す。見つからなければ `FindFailed` になる。 |
| `wait(画像, 秒)` | `find` と同じ。待つ秒数を 2 番目の引数に書ける。`wait 2` のように数だけを渡すと、その秒数だけ待つ（`sleep 2` と同じ）。 |
| `exists(画像, 秒)` | 画像があれば場所（`Match`）を、なければ `nil` を返す。 |
| `wait_vanish(画像, 秒)` | 画像が消えるまで待つ。消えたら `true`、消えなければ `false` を返す。 |

どれも、すぐに見つからなくても、0.1 秒ほどの間をおいて繰り返し探す。待つ時間は既定で 3 秒である。`exists` も同じなので、画像が無いときは、`nil` が返るまでに 3 秒かかる。すぐに結果がほしいときは、`timeout: 0` を付ける。

`wait`、`exists`、`wait_vanish` の「秒」は省略できる。書くと、下の `timeout:` と同じ意味になる（`exists "error.png", 0` は `exists "error.png", timeout: 0` と同じ）。

次のキーワード引数を付けられる。

| 引数 | 意味 | 既定 |
| --- | --- | --- |
| `timeout:` | 待つ秒数。`0` にすると、1 回だけ探す。 | 3 |
| `similarity:` | 一致度のしきい値（0 より大きく 1 以下）。大きいほど厳しい。 | 0.7 |

```ruby
find "icon.png", similarity: 0.9
wait "dialog.png", timeout: 10
if exists("error.png", timeout: 0)
  # ...
end
```

### 見つけた場所（Match）

`find`、`wait`、`exists` が返す。

| メソッド | 内容 |
| --- | --- |
| `x`、`y` | 左上の座標 |
| `w`、`h` | 幅と高さ |
| `center` | 中心の座標 `[x, y]` |
| `score` | 一致度（1.0 が完全一致） |

座標の単位は、画面の実際の画素である。表示倍率が 150% でも、フル HD の画面なら右下は (1919, 1079) である。

### 一致度について

一致度は、形の一致度と色の一致度を掛けたものである。1.0 が完全一致である。

- 形や模様が同じでも、**色が違えば低くなる**（青いボタンと灰色のボタン）。
- 形が同じでも、**濃さが違えば低くなる**（黒い文字と灰色の文字。有効なボタンと無効なボタン）。
- 単色の画像は、同じ色で塗られた場所で見つかる。
- 同じものが複数あるときは、いちばん上、その中でいちばん左のものが見つかる。

間違ったものが見つかるときは、`similarity:` を大きくするか、まわりを含めて大きめに切り取る。

## マウス

| 書式 | すること |
| --- | --- |
| `click(対象)` | クリックする。 |
| `double_click(対象)` | ダブルクリックする。 |
| `right_click(対象)` | 右クリックする。 |
| `hover(対象)` | マウスカーソルを乗せる。 |
| `drag_drop(元, 先)` | 元から先へ、ドラッグ＆ドロップする。元と先は、どちらも「対象」と同じ書き方をする。 |
| `wheel(向き, 回数)` | ホイールを回す。向きは `:up`（上）か `:down`（下）。回数はホイールの目盛りの数で、省略すると 1 になる。 |
| `wheel(対象, 向き, 回数)` | 対象の上へマウスカーソルを動かしてから、ホイールを回す。 |

対象には、次のどれかを書く。

| 対象 | 意味 |
| --- | --- |
| `"button.png"` | 画像を探し、見つけた場所の中心。見つからなければ `FindFailed` になる。 |
| `Match` | `find` などが返した場所の中心。 |
| `[x, y]` | 座標（整数）。 |
| 省略 | いまのマウスカーソルの位置。`click`、`double_click`、`right_click`、`wheel` で省略できる。 |

次のキーワード引数を付けられる。

| 引数 | 意味 | 付けられるメソッド |
| --- | --- | --- |
| `offset: [x, y]` | 対象から、右へ x、下へ y だけずらした場所にする。負の数にすると、左や上へずれる。 | `click`、`double_click`、`right_click`、`hover` |
| `timeout:`、`similarity:` | 対象を画像で書いたときの、待つ秒数と一致度のしきい値（「探す」と同じ）。 | すべて |

操作のあとには、0.2 秒の待ち時間が入る（「既定値を変える」の `Pikulix.delay`）。

```ruby
click "ok.png"
click "label.png", offset: [80, 0]   # ラベルの中心から右へ 80 画素
double_click [400, 300]

m = find "file.png"
right_click m

drag_drop "file.png", "folder.png"
wheel :down, 3
wheel "list.png", :down, 3            # list.png の上にマウスを動かしてから回す
```

## キーボード

| 書式 | すること |
| --- | --- |
| `type(文字列)` | 文字列を入力する。 |
| `key(キー, ...)` | キー操作を送る。複数を書くと、順に送る。 |
| `paste(文字列)` | クリップボード経由で貼り付ける（Ctrl+V）。 |

```ruby
type "こんにちは\n"        # \n は Enter、\t は Tab として送られる
key "ctrl+s"
key "alt+tab"
key "ctrl+c", "ctrl+v"     # 順に送る
paste "長い文章や、type を受け付けないアプリに"
```

- `type` は、キーではなく文字そのものを送る。キーボードの配列（日本語、英語）や、日本語入力（IME）のオンとオフには関係なく、書いたとおりの文字が入る。
- `type` を受け付けないアプリでは、`paste` を使う。クリップボードの元の内容は、貼り付けのあとで戻される。
- `key` は、同時に押すキーを `+` でつなぐ。大文字と小文字は区別しない。`+` の前後の空白は無視される。
- `key` は、キーを押したことにする。そのため、日本語入力（IME）がオンだと、`key "a"` は「あ」になるなど、手で打ったときと同じように変換される。文字を入力するときは、`key` ではなく `type` を使う。
- どれも、操作のあとに 0.2 秒の待ち時間が入る（「既定値を変える」の `Pikulix.delay`）。`key` に複数を書いたときは、1 つごとに入る。

`key` で使える名前（かっこの中は別名で、同じキーである）:

| 種類 | 名前 |
| --- | --- |
| 修飾キー | `ctrl`（`control`）、`shift`、`alt`、`win` |
| 文字 | `a`〜`z`、`0`〜`9` |
| 記号 | `;` や `/` など、記号そのもの。`plus`、`minus`、`comma`、`period` という名前もある。 |
| 編集 | `enter`（`return`）、`tab`、`esc`（`escape`）、`space`、`backspace`（`bs`）、`delete`（`del`）、`insert`（`ins`） |
| 移動 | `up`、`down`、`left`、`right`、`home`、`end`、`pageup`（`pgup`）、`pagedown`（`pgdn`） |
| ファンクション | `f1`〜`f24` |
| テンキー | `num0`〜`num9` |
| 日本語入力 | `kanji`（半角/全角）、`henkan`（変換）、`muhenkan`（無変換） |
| その他 | `printscreen`、`pause`、`capslock`、`numlock`、`scrolllock`、`apps`（`menu`） |

- 記号をそのまま書くと、いまのキーボードの配列で、その記号が出るキーを送る。Shift が要る記号では、Shift も一緒に送る（日本語の配列で `key "!"` と書くと、Shift+1 になる）。
- `plus`、`minus`、`comma`、`period` は、`+`、`-`、`,`、`.` のキーを、Shift を付けずに送る。
- `+` はキーをつなぐ記号でもあるので、`+` のキーを組み合わせるときは、`key "ctrl+plus"` と書く。`key "ctrl++"` とも書けるが、こちらは記号の `+` として扱うので、配列によっては Shift も一緒に送る。
- 表に無い名前を書くと、エラー（`Pikulix::Error`）になる。
- `key "alt+shift+c"` は、緊急停止のキーと同じなので、送るとスクリプトが止まる。

## その他

| 書式 | すること |
| --- | --- |
| `sleep(秒)` | 待つ。`sleep 0.5` のように小数も書ける。 |
| `run(コマンド, 引数...)` | アプリを起動する。ファイルや URL を渡すと、関連付けられたアプリで開く。起動するだけで、アプリが終わるのは待たない。引数は省略できる。 |
| `message_box(文章, タイトル)` | メッセージボックス（OK ボタンの付いた小さなウィンドウ）を表示し、OK が押されるまで待つ。タイトルは省略でき、省略すると「Pikulix」になる。 |
| `exit(終了コード)` | スクリプトを終了する。終了コードは省略でき、省略すると 0 になる。 |
| `puts`、`print`、`p` | コンソールに出力する。 |

```ruby
run "notepad.exe"
run "notepad.exe", "C:\\work\\memo.txt"
run "https://example.com/"

message_box "終わりました"
message_box "ファイルを保存しました", "お知らせ"

exit 1                     # 終了コード 1 で終わる
```

- `run` で起動したアプリの作業フォルダは、スクリプトのあるフォルダになる。
- `run` のあとにも、0.2 秒の待ち時間が入る（「既定値を変える」の `Pikulix.delay`）。アプリのウィンドウが出るのを待つには、`wait` で画像を待つ。

## ファイルの読み書き

テキストファイルを読み書きできる。入力の一覧をファイルから読んで繰り返す、結果を書き残す、といった使い方をする。

| 書式 | すること |
| --- | --- |
| `read_text(ファイル)` | ファイルの中身を文字列で返す。 |
| `write_text(ファイル, 文字列)` | 文字列をファイルに書く。無ければ作り、あれば上書きする。 |
| `append_text(ファイル, 文字列)` | 文字列をファイルの末尾に書き足す。無ければ作る。 |
| `file_exist?(ファイル)` | ファイルがあれば `true`、なければ `false` を返す。フォルダは `false` になる。 |

```ruby
# 一覧（タブ区切り）を読んで、1 行ずつ処理する
read_text("list.tsv").lines.each do |line|
  name, amount = line.chomp.split("\t")
  type name
  key "tab"
  type amount
  key "enter"
end

# 結果を書き残す
append_text "result.txt", "#{name}: 完了\n"

write_text "done.txt", "" unless file_exist?("done.txt")
```

- ファイルのパスは、画像と同じく、スクリプトのあるフォルダからの相対で書く。`C:\...` のような絶対パスも書ける。日本語のファイル名も使える。
- 文字コードは UTF-8 である。読むときは、先頭の BOM（メモ帳や Excel の「CSV UTF-8」が付ける印）は取り除かれる。UTF-16（メモ帳の「UTF-16 LE」、Excel の「Unicode テキスト」）も読める。Shift_JIS のファイル（Excel の「CSV (コンマ区切り)」など）は読めず、エラー（`Pikulix::Error`）になる。
- 書くときは、BOM を付けずに UTF-8 で書く。改行は、書いたとおりに書かれる（`\n` は `\n` のまま）。メモ帳や Excel で開くなら、どちらでも読める。
- 読んだ文字列の改行は、ファイルのままである。Windows のファイルは、たいてい `\r\n` である。1 行ずつ扱うときは、`lines` で分け、`chomp` で行末の改行を落とす（`chomp` は `\r\n` も落とす）。
- 無いファイルを読む、無いフォルダに書く、といったときはエラー（`Pikulix::Error`）になる。
- `read_text` は、ファイル全体を一度に読む。何 GB もあるファイルには向かない。

表のデータは、**タブ区切り（TSV）で、UTF-8 か UTF-16** にしておくことを勧める。タブは値の中にまず現れないので、`split("\t")` で確実に分けられる。Excel なら「名前を付けて保存」で「Unicode テキスト (*.txt)」を選ぶと、この形式になる。カンマ区切り（CSV）は、値にカンマや引用符があると `"東京都,千代田区"` のように引用符で囲まれ、`split(",")` では正しく分けられない。

## 既定値を変える

スクリプトの先頭などで、次のように書く。

```ruby
Pikulix.similarity = 0.8   # 一致度のしきい値（既定は 0.7）
Pikulix.timeout = 10       # 画像が現れるのを待つ秒数（既定は 3）
Pikulix.delay = 0.5        # 操作のあとに入れる待ち時間の秒数（既定は 0.2）
Pikulix.log = false        # ログを出さない（既定は true）
```

- 変えたあとの操作に効く。スクリプトの途中で、何度でも変えられる。
- `Pikulix.similarity` と `Pikulix.timeout` は、`similarity:` や `timeout:` を付けなかったときに使われる。
- `Pikulix.delay` の待ち時間は、マウスの操作、キーボードの操作、`run` のあとに入る。`0` にすると、待たない。

## エラー

画像が見つからないと、`FindFailed` という例外になり、スクリプトはそこで止まる。止めたくないときは、`exists` で確かめるか、`rescue` で受ける。

```ruby
begin
  click "ok.png"
rescue FindFailed
  puts "OK ボタンが無いので、次へ進みます"
end
```

`FindFailed` になったときは、そのときの画面が、`pikulix.exe` のあるフォルダの `logs` に PNG で保存される。何が写っていたかを確かめられる。古いファイルは自動では消えないので、要らなくなったら消す。

## ログ

何を探し、どこで見つけ、何をしたかが、コンソールに出力される。

```
[pikulix] click "ok.png": (300, 620) で発見（一致度 0.998、24 ms）
[pikulix] click (360, 636)
[pikulix] type "こんにちは"
```

`type` や `paste` に渡した文字列も出力される。パスワードなどを扱うときは、その間だけ `Pikulix.log = false` とするとよい。

## 操作せずに試す（テストモード）

```
pikulix.exe --screen-image 画面.png script.rb
```

画面の代わりに、指定した画像ファイルの中から探す。マウスやキーボードの操作は送られず、ログだけが出る。`logs` に保存された画面を使って、「この画像は、なぜ見つからなかったのか」を調べるのに使える。

## 使えないもの

mruby で動くので、ふつうの Ruby（CRuby）とは次の点が違う。

- gem や標準ライブラリは使えない。`require` も無い。
- `File` や `Dir` は無い。ファイルの読み書きは、「ファイルの読み書き」の `read_text` などで行う。

## 制約

- ロック画面、切断したリモートデスクトップ、UAC の確認画面（管理者の許可を求める画面）では動かない。
- 管理者として動いているアプリのウィンドウは、Pikulix も管理者として実行しないと操作できない。一部のゲームのランチャーや、タスク マネージャーなどがこれにあたる。画像は見つかり、マウスカーソルも動くが、クリックやキー入力が届かない。このときは、次の警告が出る。

  ```
  [pikulix] 警告: 操作の相手のウィンドウ「タスク マネージャー」は、管理者として動いているようです。このままでは、クリックやキー入力が届きません。Pikulix を管理者として実行してください
  ```

  管理者として実行するには、コマンドプロンプトを「管理者として実行」で開き、そこから `pikulix.exe` を実行する。
- 著作権保護された動画などは、黒く写ることがある。
